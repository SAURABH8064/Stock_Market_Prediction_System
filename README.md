# Stock Market Prediction System

## Project Overview
This project predicts future stock prices using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- Google Colab

## Features
- Data Cleaning
- EDA
- Linear Regression Model
- Stock Price Prediction
- MAE & RMSE Evaluation
- Actual vs Predicted Graph
